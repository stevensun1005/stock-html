# 自检：三层都要过

版面问题（文字压线、互相重叠）靠肉眼读代码发现不了，必须渲染出来查。三层检查一层比一层准，缺一不可。

## 第一层：离线预检(`page.save()` 自动跑)

`sketch.py` 按字符估算每段 SVG 文字的宽度，在写文件的同时检查：

| 报错 | 含义 | 怎么改 |
|---|---|---|
| `[越界]` | 文字超出这张图的 viewBox | 挪位置、换 `anchor`、缩短文字 |
| `[压格线]` | 漫画里的文字没有完整落在某一格内（留 3px 边） | 往格子中间挪；文字太长就改短 |
| `[文字重叠]` | 同一张图里两段文字的框相交 | 拉开间距（行距 ≥ 1.5 倍字号）或删一个标签 |
| `[说明超长]` | 格子说明超过 15 字（英文 32 字符） | 改短，不要缩字号 |
| `[正文超 4 句]` | 某节正文超过 4 句 | 删；细节放进图、表或小字注 |
| `[代价不能留空]` | 卡片的"代价是什么"空着或写了"没有代价" | 再想：时间、钱、确定性、灵活性，总有一样 |
| `[依赖链断了]` | 某个概念说不出它带来什么新问题 | 排错了，重排 |
| `[链接未核实]` | `Stop` 给了 url 但没有 `verified=True` | 用抓取工具打开核实；核实不了就去掉 url |
| `[主线必须是一句话]` | 主线写成了一段 | 压成一句 |
| `warn [缺小节]` | 股票报告缺默认章节 | 补上；确实不适用时在回复里向用户说明原因 |
| `warn [体检单这一行没有具体数字]` | 体检单某行没有数字 | 补数字和口径 |

有 `ERROR` 时脚本以退出码 1 结束（文件照样写出）。估算宽度和真实渲染有 ±5% 的出入，所以预检通过不等于没问题——继续第二层。

## 第二层：真实渲染(`verify.py`)

```bash
python3 scripts/verify.py out.html                     # 只跑自检
python3 scripts/verify.py out.html --shots shots/      # 自检 + 按屏切片截图(浅色、深色各一套)
python3 scripts/verify.py out.html --shots shots/ --at paths,risks,c3   # 只截指定小节（高度自动）
python3 scripts/verify.py out.html --shots shots/ --full   # 另存整页长图
python3 scripts/verify.py out.html --pdf out.pdf           # 另存 A4 PDF（浅色主题，图和卡片不跨页）
```

它用无头 Chrome / Chromium / Edge 打开页面，读出模板里内置自检脚本的结果。内置脚本在字体加载完成后，对每张 `svg.chk` 用 `getBBox()` 量真实文字框，检查五类问题：

- `overflow` 文字超出 viewBox
- `overlap` 同一张图里两个文字框相交
- `panel` 漫画文字没有完整落在某个 `rect.panel` 内
- `caption` 带 `cap` class 的格子说明超字数
- `wobble` 有 `<text>` 被放进了带滤镜的组（文字会跟着抖）

浅色、深色各跑一遍，输出 `[CHECK light] PASS` / `[CHECK dark] PASS`；任何一类非空就是 FAIL，并列出是哪张图的哪段文字。**两个主题都 PASS 才能交付。**

小节 id(给 `--at` 用):`mainline` `checkup` `moat` `chain` `cards` `c1`…`cN`(第 N 张卡片)`roadmap` `vision` `risks` `timeline` `paths` `ruler` `eli5` `route`。

### 没有 Chrome 的环境

`verify.py` 以退出码 2 结束并提示备用办法，任选其一：

- 设环境变量 `CHROME=/path/to/chrome` 指向任何 Chromium 内核浏览器。
- 在任何浏览器里打开 `out.html?check=1`：页面底部出现检查条（绿 = PASS，红 = FAIL 并列出问题）；控制台里也有 `[CHECK light]` / `[CHECK dark]` 两行。
- 发布为 Artifact 后读控制台日志(例如 claude.ai 环境里的 `verify_artifact`)，同样看这两行。
- URL 参数可以组合：`?theme=dark`(指定主题)、`?at=paths`(把某一节顶到最上面)、`?slice=2&sliceh=1300`(上移两屏)。在只能截首屏的环境里，用它们逐段截图；做不到带参数打开时，生成几份"加载后自动滚到某一节"的调试副本，看完删除。

## 第三层：看图

自检只查文字框，查不出"难看"。`--shots` 之后**逐张看截图**，浅色、深色至少各看两段，重点找：

- 文字贴着线、标签挤成一团（没重叠但读不清）
- 文字压在图形上（自检不查文字和图形的碰撞）
- 图例或列表里的小图标被撑大
- 印章被遮住，或英文副标题断行后撞到印章
- 概率色带里的字太挤；时间轴上相邻标签太近
- 深色主题下某个颜色看不清
- 漫画看不懂：遮住说明文字，只看图，能不能猜出在讲什么

发现问题 → 改 build 脚本 → 重新生成 → 重新 `verify.py`。不要直接改产出的 HTML。
