# 视觉规范：卡通手绘

`assets/template.html` 和 `scripts/sketch.py` 已经实现了下面全部规范。读这一份是为了两种情况：**自己用 `Canvas` 画新图**，或者**不能跑 Python、要手写 HTML**。

## 底色与主题

- 浅色 = **方格纸**：两层 CSS 渐变画大格（100px）和小格（20px）。
- 深色 = **黑板粉笔**：深绿底 + 轻微径向渐变和斜纹。
- 两套主题都要做，全部走 CSS 变量。跟随系统 `prefers-color-scheme`，也可以由右上角按钮切换(写到 `<html data-theme>`)。
- 切换按钮用 `position:absolute` 放在页头右上角。**不要用 fixed**——滚动时会盖住卡片右上角的印章。

## 字体（不加任何外链）

部分 Artifact 环境的 CSP 会拦截外链字体并在控制台报错，所以只写带本地回退的字体栈：

- 标题手写体：`"Patrick Hand","Chalkboard SE","Comic Sans MS","Segoe Print","Ma Shan Zheng","HanziPen SC","Hannotate SC","Kaiti SC","STKaiti","KaiTi","楷体",cursive`(英文、数字先命中前几个，中文落到后面的手写 / 楷体)
- **正文和 SVG 里的全部文字：系统无衬线**(`-apple-system,"PingFang SC","Microsoft YaHei","Noto Sans CJK SC",sans-serif`)——可读，字宽也可预测，离线预检才估得准。

## 卡片

- 不规则圆角：`border-radius: 18px 6px 20px 8px / 8px 20px 6px 18px`
- 轻微旋转：−0.6° ~ 0.6°，用 `:nth-of-type` 轮换（窄屏取消）
- 硬阴影：`box-shadow: 5px 5px 0 var(--shadow)`
- 标题右侧留 `padding-right: 96px` 给印章；英文副标题 `white-space:nowrap; display:inline-block`，避免断行后撞到印章

## 固定颜色语义（全页一致，不许混用）

| 颜色名 | 含义 | 用在哪 |
|---|---|---|
| `green` | 正在进行的东西 | 业务、利润、正在发生的流动 |
| `orange` | 新来的东西 | 新事件、新股东、新股、还没发生的计划 |
| `blue` | 存起来的东西 | 股份、现金、价值、价格 |
| `red` + 虚线 | 被释放 / 作废的东西 | 损失、作废的价值、缺口 |
| `purple` | 只给印章用 | 避免和"作废"的红色冲突 |
| `ink` / `ink2` | 墨线 / 次要说明 | 轮廓、坐标轴、小字 |

页头自带图例。注意全局 `svg{width:100%}` 会把小图标撑大——图例和列表里的小图标要单独写死宽高（模板已处理）。

## SVG 的规矩

**只抖图形，不抖文字。** 滤镜全页只定义一次，所有图引用同一个 id:

```html
<svg class="chk" viewBox="0 0 760 300" data-name="图名">
  <g filter="url(#wob)"> <!-- 线条、方框、箭头 --> </g>
  <g> <!-- 所有 <text>:不加 filter,不加 transform --> </g>
</svg>
```

- 描边和填充都用 class + CSS 变量（主题切换时图跟着变色），不要写死颜色：
  - 图形基础 class `sh`；描边 `k-ink` `k-green` `k-orange` `k-blue` `k-red` `k-none`;
  - 浅色填充 `f-green` `f-orange` `f-blue` `f-red` `f-card` `f-paper` `f-hl` `f-none`；实心填充 `fs-green` …；
  - 线型 `dash`(虚线)`dot`(点线)`thin` `bold`;
  - 文字颜色 `c-ink` `c-ink2` `c-green` …，加粗 `b`。
- 给 `<svg>` 加 class `chk`，内置自检才会检查它；`data-name` 用来在报告里指出是哪张图。
- 单独一条水平或垂直的线放在带滤镜的 `<g>` 里会消失（滤镜区域按包围盒算，高度为 0）。同组里再放任意一个有面积的图形即可；`Canvas` 画的图通常不会遇到。
- **所有图手写内联 SVG，不用 Chart.js / D3 / Mermaid。** 用脚本批量生成 SVG 是对的。

## 画布尺寸

| 用途 | viewBox | 说明 |
|---|---|---|
| 两格漫画 | `0 0 560 232` | 左格 x 8–272（中心 140），右格 x 288–552（中心 420）；格子是 `rect.panel`；绘图区 y 44–188；格子说明在 y≈211,class `cap` |
| 大图 | 宽 760 | 字号不小于 12（窄面板里缩放后才看得清），重要标签 13.5–15 |
| 体检单图标 | `0 0 26 26` | 固定 26px，不随容器缩放 |

漫画格子里常用的占位：小人 `person` 约 30×60；小店 `shop` 默认 64×66（含屋顶）；一枚硬币 17px 见方；气泡自定宽高，尾巴另占 12px 高。

## 两格漫画怎么画

- 左格 = **烦恼**（没有这个概念时会发生什么），右格 = **办法**（这个概念怎么解决）。
- 每格只讲一件事：1–2 个角色 + 1 个道具 + ≤ 2 个短标签。画不下说明想讲的太多。
- 格子说明 ≤ 15 字，连数字和符号一起数。超了改短，不要缩字号。
- 表情就是情绪：烦恼格用 `mood="sad"`，办法格用 `"happy"`。
- 同一个东西在全页长一个样：BOBA 永远是绿色小店，D 永远是橙色小人。

## 进度印章

每张卡片右上角一个手绘印章，三种状态：**下一站**（虚线框）/ **补一下**（单线框）/ **已学**（双线框）。旋转 −12°，紫色。读者点一下循环切换，状态存在 `localStorage`(读不到也不影响页面);"已学 n / m"的计数跟着变。

## 改代码时的注意

批量改字号、改坐标，不要用"替换匹配串里第一个出现的数字"这种正则——坐标里也可能含相同数字（712 里的 12）。逐条精确替换，替换后断言每条只命中一次。优先改 build 脚本然后重新生成，不要直接改产出的 HTML。
