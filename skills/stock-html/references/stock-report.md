## 数据纪律

1. **先研究，后动手。** 所有数字在写页面之前核实完毕。新闻以公司公告 / 8-K / 新闻稿为准；二手媒体和一手冲突时，以一手为准。二手媒体说"没有新消息"不算数，自己去查公告和 SEC 文件。
2. **用户截图里的价格直接用**，并注明"价格来自你的截图"。由截图涨跌幅反推的昨收等数字，标"反推"。
3. **推算值全部标"示意"或"示意估算"**，并在正文或小字注里给出算法。
4. **先算平再画图。** build 脚本最上面放所有输入，推算写成表达式，用 `assert` 对账：涨跌幅分解之和 = 总涨跌幅；价差 = 1 − 市价 ÷ 换股价值；增厚 / 摊薄 = 新 EPS ÷ 旧 EPS − 1；参考价位 = EPS × 倍数。页面上出现的每个数都应该能在脚本里找到来处。
5. **未确认的日期不写死。** 写"预计 12 月初（去年为 12/2，以公司公告为准）"。
6. **不提用户的持仓和期权**，只分析股票本身。不给"买 / 卖 / 加仓"指令；"参考价位"是方法演示，不是建议。
7. **页脚列出全部来源**（一手在前），并保留"仅作学习用途，不构成投资建议"。

每个数字在心里过一遍三问：**哪来的？什么口径（GAAP / 非 GAAP、TTM / 单季、稀释 / 基本）？截至哪天？** 答不上来就不能用。

## 1 主线

`p.mainline(一句话, canvas, kind=…, note=…)`

找一条贯穿全部概念的主线，必须是三者之一：**主循环**（周而复始的流程）、**流水线**（单向的加工链）、**核心矛盾**（两个互相拉扯的力）。呈现方式是**一句话 + 一张图**：读者看完就知道"这件事到底在干什么"。

- 一句话就是一句话，不是一段。
- 图下面用 `note` 交代固定角色和缩小比例："A、B、C = 老股东；D = 新股东；1 块饼 = 1 亿股"。

## 2 体检单

`p.checkup([("ok" | "mid" | "bad", "…"), ...], small="基本面变了吗?")`

主线下面紧跟体检单，回答用户最关心的那个是非题。

- ✓ 绿勾 = 没变 / 变好；— 橙横 = 中性 / 有代价；✗ 红叉 = 变差 / 新风险。
- **每行必须带具体数字和口径**，例如"Q3 收入预告落在指引中点 $31.5 亿"。没有数字的行会被预检警告。
- 5–7 行。好消息和坏消息都要有；全是绿勾说明没认真找。

## 3 核心竞争力

`p.section("核心竞争力:…", prose, canvas=护城河图, tiles=[(名称, 证据, 弱点), ...], role="moat")`

**要回答：哪 2–3 件事别人真的抄不走？**

- 每条竞争力写成三件套：**是什么 → 证据数字（带口径）→ 弱点 / 谁能抄走、要多久**。
- 证据要能量化：市占率、毛利率比同行高几个点、客户留存率、切换成本（迁移要几个月）、专利 / 牌照数量、单位成本、规模（门店数、装机量）。
- 第一句结论要排序：哪条最深、哪条最浅。
- 图：几道护城河的同心弧（见示例），或和同行的对比条。
- **反例**:"品牌强大""技术领先""管理层优秀"——没有数字的形容词一律删掉或换成证据。
- 找不到两条有证据的竞争力，就如实写"护城河不深"，不要凑。

## 4–5 概念依赖链与卡片

`p.chain([(概念, 它带来的新问题), ...])`，然后 `p.card(...)` × N。

- 先读完全部材料再列概念，8–13 个。
- **按依赖排，不按材料顺序排**：概念 A → 带来问题 X → 概念 B 解决 X → 但 B 带来问题 Y → 概念 C 解决 Y……
- 每个节点下面一句"带来：XX"（≤ 10 个字）。写不出来 = 排错了。
- 卡片 = 顶部一句定义（含英文原词）+ 两格漫画（左：没有这个概念时的烦恼；右：这个概念的办法）+ 两行（"解决了什么""代价是什么"），**不写第三行**。
- 链上的概念和卡片必须一一对应（预检会查）。
- 印章初始状态：你判断读者大概率已经懂的给 `"done"`，需要回头补的给 `"redo"`，其余 `"next"`；读者可以自己点着改。

## 6 技术规划路线

`p.section("技术规划路线:…", prose, canvas=roadmap([(时间, 标题, [要点]), ...]), role="roadmap")`

**要回答：现在做到哪、下一步是什么、哪些只是愿景？**

- 三级台阶：**现在**（已量产 / 已发布 / 已上线）→ **下一步**（公司给了时间表）→ **以后**（只有方向，没有时间表）。
- 每级 2–3 个要点，尽量带数：良率、制程节点、产能、装机量、单位成本、发布日期。
- 严格区分三种状态并写在要点里：**已经做到** / **公司承诺了时间** / **只是愿景**。
- 来源优先级：技术日 / 投资者日材料 > 财报电话会 > 产品发布 > 媒体报道。
- 正文第一句说清这条路线**在解决什么**（降成本？提性能？开新市场？），以及最大的不确定性在哪一级。
- 不是科技公司也要写这一节：换成**产品 / 产能 / 渠道路线**（新店型、新工厂、新品类）。标题可以相应改，`role="roadmap"` 不变。

## 7 远期规划

`p.section("远期规划:…", prose, canvas=对比图, role="vision", note="算法:…")`

**要回答：管理层 3–5 年要去哪？按现在的速度到得了吗？**

- 写清目标本身：收入 / 利润率 / 产能 / 市占率 / 门店数，以及目标年份。
- **必须做一次对账**：按最近的实际速度外推到目标年份是多少 → 和目标差多少 → 要达标每年得做到多少。把这三个数画在一张图上（现在 / 按现速 / 目标，差额用红色虚线）。
- 区分 **指引**（guidance，公司对近期业绩的正式预期）和 **目标 / 愿景**(aspiration)。后者不能当成业绩来算估值。
- 说明目标靠什么钱实现：现金流够不够，还是要借钱 / 增发。
- 算法写在 `note` 里。

## 8 隐藏危机

`p.section("隐藏危机:…", prose, canvas=risk_matrix([...]), table=(["危机", "为什么容易被忽略", "预警信号"], rows), role="risks")`

**要回答：公告和多头叙事里没写的是什么？**

- 4–6 条，**至少一半是市场没在讨论的**。去这些地方找：财报附注、10-K 的 Risk Factors、客户 / 供应商集中度、存货和应收账款周转、股权激励带来的稀释、债务到期墙、表外承诺、关联交易、会计政策变更、监管与诉讼、技术替代、关键人物依赖。
- 每条给三样东西：**为什么容易被忽略** + **传导路径**（它怎么一步步变成利润或估值的损失）+ **预警信号**（盯哪个数、到多少算亮灯）。
- `risk_matrix` 的横轴是发生的可能、纵轴是杀伤力，位置是主观估计（图上自动注明）。结论句点名"最该盯哪一个"，通常是右上角那个，不是最吓人的那个。
- **反例**:"宏观经济不确定性""行业竞争加剧""地缘政治风险"——没有传导路径和预警数字的套话不算危机。

## 9 关键时间节点

`p.section("关键时间节点", prose, canvas=timeline([...]), table=(["什么时候", "什么事", "看什么", "日期确认了吗"], rows), role="timeline")`

**要回答：未来 6–12 个月，哪几天会出结果？**

- 4–7 个节点：财报日、产品发布 / 量产、监管审批或诉讼期限、股东大会、解禁日、指数调整、债务到期、行业大会、重要客户的财报。
- 每个节点写"看什么"：不是"关注财报"，而是"毛利率能不能回到 40% 以上"。
- 已确认的日期（公司公告 / 合同约定）画实心点；未确认的 `sure=False` 画虚线圈，日期写"预计 1 月下旬"，表格里注明依据（"去年是 1/28"）。
- 时间轴上放一个 `now=True` 的"今天"。
- 股价推演里每条路径的触发条件，应该能在这张时间表里找到对应的日子。

## 10 股价推演

`p.section("股价推演:…", prose, canvas=paths_chart(history, scenarios), table=推演表, after="下一份财报后的机会:…", note="算法…", role="paths")`

**要回答：2–3 条路各需要发生什么、落在哪、主观概率多少？**

- 一张图：左边历史价格折线，右边 2–3 条分叉，终点是价格区间色带，色带里写"名称 + 概率"（单行）。概率之和必须是 100。
- **参考价位用可复算的公式推出**，并写明推导。默认：`示意 EPS = 公司收入展望 × 最近一季非 GAAP 净利率 ÷ 稀释股数`，再乘 20 / 22 / 25 倍等倍数；倍数的依据（历史区间、同行）一句话交代。
- 推演表每条路径一行：**需要发生什么**（对应到关键时间节点里的事件）、示意 EPS × 倍数、价格区间、概率。
- 概率一律标"主观估计，不是预测"（图上自动带）。
- 加一段"财报后的机会"(`after`,≤ 4 句)：下一份财报看什么；哪种情况是右侧确认信号；哪种情况才谈得上分批。只讲条件，不讲指令。

## 11 尺子

`p.section("一把尺子:…", prose, canvas=ruler_chart(...), table=(["办法", "改善哪个指标", "牺牲哪个指标"], rows), role="ruler")`

这个领域衡量好坏的 2–3 个指标，画在**同一张图**上。股票类默认：x = 每股盈利，y = 倍数（P/E），等股价虚线（同一条线上股价相同），旁边一根"确定性"量杯。把"公告前 / 今天 / 各条路径"都标成点。

配一张表：前面每个办法（概念）通常**改善哪个指标、牺牲哪个指标**。

## 12 零基础版

`p.section("零基础版:…?", prose, canvas=waterfall(...), steps=[…], table=对比表, role="eli5")`

材料里最容易卡住、最反直觉的那个机制单独一节（按需，但大多数材料都有一个）：

- 标题就是读者会问的那个问题（"为什么被收购方跌得比收购方还多？"）。
- 编号步骤写清**每一步发生了什么**，带完整算式。
- 一张图（瀑布图拆解涨跌幅）。
- 一张对比表（做法 A vs 做法 B，逐行对照）。

## 13 学习路线

`p.route([Stop(name, why, time, url, link_text, verified=True), ...])`

3–4 站，地铁线路图 + 每站一张小卡：为什么去、去多久、链接。

> **链接必须用抓取工具打开核实，内容对得上才能写 `verified=True`。** 被拦截（403）或打不开就换一个；实在没有就不给 `url`，页面会显示"需自行搜索"。优先一手来源（公司新闻稿、SEC 文件、财报）。编造链接是这个技能最严重的失败。

## 还可以加的节

默认结构是底线。材料里有这些内容时主动加 `section()`(不需要 `role`):

- **估值与同行对比**：同一把尺子上放 3–5 家同行。
- **管理层与资本配置**：回购、分红、并购记录、股权激励。
- **财务质量**：自由现金流 vs 净利润、负债结构、存货与应收。
- **客户 / 供应链集中度**：前五大客户占比、单一供应商依赖。
- **这次财报的三张表**：只挑变化最大的 3–5 个科目图解。

## 并购类专题

并购新闻的典型卡点是"为什么被收购方跌得比收购方还多"，放进零基础版：

- 被收购方股价 = 收购方股价 × 换股比例 ×（1 − 价差）
- 涨跌幅拆两刀：收购方自己的涨跌 + 价差的变化；两刀相乘（不是相加）等于总涨跌幅，断言里要验证。
- 对比表："直接买收购方" vs "买被收购方等换股"——花多少、交割后拿到什么、便宜多少、交易告吹时会怎样、你在赌什么。
- 体检单里必须有：换股比例、新发股数与稀释比例、增厚 / 摊薄（含与不含协同）、分手费、审批状态与期限。
